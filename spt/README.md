# 🧪 spt — Análisis de ensayos SPT

> Módulo para tratamiento e interpretación de resultados de ensayos de penetración estándar (SPT).

---

## 📌 Descripción general

**spt** está orientado al análisis de resultados de ensayos **SPT** (Standard Penetration Test), ampliamente utilizados para caracterizar suelos y estimar parámetros de resistencia, densidad y comportamiento geotécnico.

El módulo permite estructurar la información obtenida en campo, realizar transformaciones útiles para diseño y apoyar la interpretación del perfil del terreno.

---

## 🧩 Funcionalidades principales

- Procesado de resultados de ensayos SPT
- Interpretación de resistencia del suelo
- Categorización del perfil geotécnico
- Base para cálculos de cimentación y estabilidad
- Apoyo a estudios de suelo en proyectos de ingeniería

## 🚀 Uso recomendado

Se usa para:

- Análisis de perfiles del terreno a partir de datos SPT
- Estimación de parámetros geotécnicos de referencia
- Evaluación preliminar de suelos para cimentaciones
- Preparación de información para otros módulos del repositorio

## 📊 Resultados esperados

- Perfiles geotécnicos interpretados
- Parámetros de terreno derivados del ensayo
- Base para diseño geotécnico y cálculo de cimentaciones
